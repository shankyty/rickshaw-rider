# Rickshaw Rider

A combat racer where you drive an auto-rickshaw through Mumbai, Hyderabad, Delhi and Chennai.

**Play in your browser: https://shankyty.github.io/rickshaw-rider/**

## Install on a Mac

```bash
brew tap shankyty/rickshaw-rider https://github.com/shankyty/rickshaw-rider
brew trust shankyty/rickshaw-rider
brew install --cask rickshaw-rider
```

This works on Apple Silicon and Intel Macs running macOS 13 or later. You can also download `RickshawRider.dmg` from [Releases](https://github.com/shankyty/rickshaw-rider/releases).

This repo holds only the published game: the website (`gh-pages` branch), the Mac releases and the Homebrew cask.
